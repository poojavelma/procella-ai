# Procella AI

Marketing website for Procella AI, an AI implementation service for small accounting, legal, and medical/dental practices.

**Live site:** [procellaai.com](https://procellaai.com)

## What's in this repo

- `index.html` — main site: hero, industries served, results, guarantee, free AI readiness audit tool, FAQ
- `assistant.html` — internal tool used during client calls; not linked from the public site (see `robots.txt`)
- `privacy.html` / `terms.html` — privacy policy and terms of service
- `robots.txt` — crawler rules
- `CNAME` — custom domain config for GitHub Pages

## Stack

Static HTML/CSS/JS, no build step, no frameworks. Hosted on GitHub Pages with a custom domain via Namecheap.

## Status

Early-stage. Privacy Policy and Terms of Service are working drafts and have not yet been reviewed by an attorney — see the banners on those pages.
